**ฟอนต์ในเครื่องครบตาม CrossPoint 2.0**

- **ฟอนต์ในเครื่องสร้างใหม่** จากไฟล์ SarabunTH ต้นฉบับ (ตอนนี้อยู่ใน repo แล้ว) ได้ตัว Ə/ə และตัวละตินสำรองของ
  ฟอนต์เมนูที่ 2.0 เพิ่มไว้ ซึ่ง 2.0.0-th.1 ยังไม่มี ตัวอักษรไทยแสดงผลเหมือนเดิม
- **หนังสือทุกเล่มจะจัดหน้าใหม่หนึ่งครั้ง** ตอนเปิดครั้งแรกหลังอัปเดต
- ตัวอักษรเวียดนามบนเมนูเปลี่ยนให้ตรงกับ CrossPoint 2.0

เทสแล้วบน X4 เครื่องจริง (หนังสือที่จัดหน้าไว้แล้วจัดใหม่ อ่านไทย เมนู) และ eink-qemu
ยังไม่ได้เทส: X4 Pro และ X4 Classic บนเครื่องจริง, OTA

**Built-in fonts now match CrossPoint 2.0**

- **The built-in fonts are regenerated** from the SarabunTH source fonts, which are now in the repository. They
  gain 2.0's Ə/ə and the Latin fallback for UI fonts, which 2.0.0-th.1 lacked. Thai looks the same as before.
- **Every book is laid out again once**, the first time it is opened after the update.
- Vietnamese letters in the menus change to match CrossPoint 2.0.

Tested on a real X4 (a book laid out by 2.0.0-th.1 laid out again, Thai reading, menus) and in eink-qemu.
Not tested: X4 Pro and X4 Classic hardware, OTA.
