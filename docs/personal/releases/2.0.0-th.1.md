**ย้ายมาใช้ CrossPoint 2.0: ไฮไลต์และเก็บข้อความ จัดหน้า EPUB ได้ดีขึ้น ปลั๊กอิน และหน้าเว็บแบบใหม่**

เฟิร์มแวร์นี้ต่อยอดจาก CrossPoint 2.0.0rc แทน 1.6.5 ทุกอย่างของ fork ยังอยู่ครบ (อ่านไทย แอป ธีมปกเต็ม/มินิมอล
สถิติการอ่าน แดชบอร์ด รีโมต Bluetooth แปลง PDF เป็น XTC)

- **ได้จาก 2.0:** เลือกข้อความเพื่อไฮไลต์หรือเก็บไว้ (เมนูในหน้าอ่าน) และค้นพจนานุกรมเป็นวลีได้
  จัดหน้า EPUB ได้มากขึ้น (drop cap, small caps, กรอบ, ตาราง, รูป GIF) ตั้งการเยื้องย่อหน้าได้ เปิดรูป JPEG
  OPDS 2.0 อัปโหลดฟอนต์ .ttf/.otf จากหน้าเว็บ และหน้าตั้งค่าที่แบ่งเป็นกลุ่ม
- **ปลั๊กอินจากการ์ด SD** เปิดได้ที่ *การตั้งค่า → การเชื่อมต่อ → ปลั๊กอิน* ช่องเดียวกับ OPDS บนหน้าหลัก
  จะเปลี่ยนเป็น "ปลั๊กอิน" ส่วนแอปของ fork ยังอยู่ที่ปุ่ม "แอป" เหมือนเดิม
- **หน้าเว็บหน้าตาใหม่** ตามต้นทาง หน้าแรกยังมีที่อยู่ IP ตัวใหญ่และปุ่มลัด (รวมสถิติการอ่านบน x4.lan)
  การแปลง PDF เป็น XTC และตัวเลือกอัปโหลดที่ไม่ล้นจอมือถือยังอยู่
- **ไฟล์ TXT เปิดด้วยตัวอ่านเดียวกับ EPUB** ตามต้นทาง ตัดคำไทยได้เหมือนเดิม ตำแหน่งที่อ่านใน TXT เดิมอาจเริ่มใหม่
- **Noto Serif ไม่ได้อยู่ในเฟิร์มแวร์แล้ว** เครื่องที่ใช้ fork นี้อยู่ยังเป็น Noto Sans เหมือนเดิม
- **เมนูภาษาไทยครบ** ข้อความใหม่ของ 2.0 แปลครบทั้ง 102 ข้อความ
- **ภาษาเมนูเหลือแค่ไทยและอังกฤษ** เพื่อประหยัดพื้นที่ ถ้าตั้งภาษาอื่นไว้ เมนูจะเป็นภาษาอังกฤษ
- หนังสือทุกเล่มจะจัดหน้าใหม่ตอนเปิดครั้งแรก

เทสแล้วบน X4 เครื่องจริง (อ่านไทย แอป ตั้งค่า Wi-Fi อัปโหลด PDF/EPUB) และ eink-qemu
ยังไม่ได้เทส: X4 Pro และ X4 Classic บนเครื่องจริง, รีโมต Bluetooth, OTA, ปลั๊กอิน และการย้อนกลับไป 1.6.5-th.10

ข้อจำกัดที่รู้: ฟอนต์ในเครื่องยังไม่มี Ə/ə (ภาษาอาเซอร์ไบจาน) และตัวละตินสำรองของฟอนต์เมนูที่ 2.0 เพิ่มมา
เฟิร์มแวร์ X4 ใช้พื้นที่ 91% ของ app slot

**Now on CrossPoint 2.0: highlights and clippings, better EPUB layout, plugins and a new web UI**

This build is based on CrossPoint 2.0.0rc instead of 1.6.5. Everything the fork adds is kept (Thai reading, apps,
the Cover/Minimal themes, reading stats, the dashboard, the Bluetooth page turner, PDF to XTC).

- **From 2.0:** select text to highlight or save it as a clipping (reader menu), and look up phrases in the
  dictionary. Better EPUB layout (drop caps, small caps, borders, tables, GIF images), a paragraph indent setting,
  a JPEG viewer, OPDS 2.0, .ttf/.otf font upload from the web page, and grouped settings.
- **SD-card plugins:** turn on under *Settings → Connectivity → Plugins*; the OPDS slot on Home then becomes
  "Plugins". The fork's apps stay on the Apps tile.
- **New web UI look** from upstream. The home page keeps the large IP address and shortcuts (including reading
  stats on x4.lan); PDF to XTC and upload options that fit a phone are kept.
- **TXT files open in the EPUB reader**, as upstream does now. Thai still breaks between words; reading positions in
  TXT files may start over.
- **Noto Serif is no longer built in.** Devices on this fork stay on Noto Sans.
- **The Thai UI is complete:** all 102 new 2.0 strings are translated.
- **UI languages are now English and Thai only**, to save flash; any other saved language shows English.
- Every book is laid out again the first time it is opened.

Tested on a real X4 (Thai reading, apps, settings, Wi-Fi, PDF/EPUB upload) and in eink-qemu. Not tested: X4 Pro and
X4 Classic hardware, Bluetooth remotes, OTA, plugins, and going back to 1.6.5-th.10.

Known limits: the built-in fonts do not yet have upstream 2.0's Azerbaijani Ə/ə or the Latin fallback for UI fonts.
The X4 firmware uses 91% of the app slot.
