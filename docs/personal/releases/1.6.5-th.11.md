**แก้ช่องโหว่: ไฟล์รหัส Wi-Fi ถูกอ่านได้ผ่าน File Transfer**

- **ปิดช่องที่ทำให้คนใน Wi-Fi เดียวกันโหลดรหัส Wi-Fi, OPDS และ KOReader Sync ไปได้** ตอนเปิด File Transfer
  เดิมเครื่องกันแค่ชื่อที่ขึ้นต้นด้วยจุด (`/.crosspoint/...`) แต่การ์ด SD เปิดไฟล์เดียวกันได้ด้วยชื่อสั้นแบบ 8.3
  (`/CROSSP~1/WIFI.JSON`) หรือชื่อที่มีเว้นวรรคนำหน้า ตอนนี้กันทุกแบบ ทั้งหน้าไฟล์ (โหลด อัปโหลด เปลี่ยนชื่อ ย้าย ลบ
  ดูรายการ) และ WebDAV ทุกคำสั่ง
- แนะนำให้อัปเดต ถ้าเคยเปิด File Transfer บน Wi-Fi ที่มีคนอื่นใช้ร่วม (หอ ที่ทำงาน ร้านกาแฟ) ควรเปลี่ยนรหัส Wi-Fi
  และรหัส OPDS/KOReader ที่บันทึกไว้ด้วย
- ไม่มีอะไรเปลี่ยนในการใช้งานปกติ ไฟล์หนังสือโหลด/อัปโหลดได้เหมือนเดิม

**Security fix: the Wi-Fi password file could be read through File Transfer**

- **Anyone on the same Wi-Fi could download the saved Wi-Fi, OPDS and KOReader Sync passwords** while File
  Transfer was on. The device only refused names starting with a dot (`/.crosspoint/...`), but the SD card opens
  the same files by their 8.3 short name (`/CROSSP~1/WIFI.JSON`) or with a leading space. Every spelling is refused
  now, on the file page (download, upload, rename, move, delete, listing) and on every WebDAV method.
- Please update. If you have used File Transfer on a shared network (dorm, office, café), change the Wi-Fi password
  and the saved OPDS/KOReader passwords too.
- Nothing else changes: books upload and download as before.
