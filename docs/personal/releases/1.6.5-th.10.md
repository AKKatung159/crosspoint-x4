**X4 Pro: แตะตรงทุกธีม เล่นแอปด้วยจอสัมผัสได้ และไฟล์สำหรับ X4 Classic**

- **แก้ X4 Pro แตะไอคอนแล้วเข้าผิดหน้า** ในธีม ปกเต็ม, มินิมอล (แตะไอคอนไหนก็เข้าเรียกดูไฟล์ แตะปกไม่เปิดหนังสือ)
  และ Cover Grid (ไอคอนเลื่อนไปหนึ่งช่องเพราะไม่มีปุ่มแอป และเข้าหน้าตั้งค่าไม่ได้) ตอนนี้ตรงทุกธีม
  Cover Grid มีไอคอนแอปแล้ว (บน X4 ที่ใช้ปุ่มก็เลือกแอปได้ถูกด้วย)
- **แอปบน X4 Pro ใช้จอสัมผัสแทนปุ่มได้** ในหน้าแอปจะมีแถบปุ่ม 4 ช่องด้านล่าง (กลับ / เลือก / < / >)
  แตะ = กดปุ่ม กดค้าง = กดปุ่มค้าง (เช่นปักธงในเกมกู้ระเบิด) และปัดซ้าย/ขวา/ขึ้น/ลง = ลูกศร (เช่นเลื่อนใน 2048)
  ใช้ได้กับทุกแอป รวมถึงแอปจาก Pocket SDK บน X4 ไม่มีอะไรเปลี่ยน
- **มีไฟล์สำหรับ Xteink X4 Classic** `crosspoint-1.6.5-th.10-x4c.bin` (ปุ่ม 7 ปุ่มเหมือน X4 ใช้แอปได้ครบ)
  ยังไม่ได้เทสบนเครื่องจริง และไม่มี emulator สำหรับรุ่นนี้

- **แก้เมนูหน้าหลักล้นจอตอนเปิด OPDS** (ธีม Classic, Lyra 3 ปก, RoundedRaff บน X4 และ X4 Pro): มี 6 รายการ
  เพราะมีปุ่มแอปเพิ่ม ตอนนี้แถวจะชิดกันขึ้นเองเมื่อพื้นที่ไม่พอ รายการสุดท้ายอยู่เหนือแถบปุ่ม และการแตะตรงกับที่วาด
- **หน้าเว็บบนมือถือ:** ตัวเลือก Optimize EPUB แบบ Advanced Mode (คุณภาพ JPEG, รุ่นเครื่อง, ทิศหมุน, ส่วนซ้อน)
  ไม่ล้นจอแล้ว ปุ่มขึ้นบรรทัดใหม่และกว้างเต็มแผ่น

ไฟล์ X4 Pro ใน th.7–th.9 ถูกนำออกเพราะบั๊กการแตะ ให้ใช้ไฟล์ของ release นี้

**X4 Pro: taps land right in every theme, apps playable by touch, and an X4 Classic file**

- **Fixed wrong targets on tap on the X4 Pro** in the Cover and Minimal themes (every icon opened Browse Files,
  and tapping the cover did nothing) and Cover Grid (icons shifted by one because the Apps tile was missing, and
  Settings could not be reached). Every theme is right now. Cover Grid shows the Apps icon (which also fixes picking
  it with buttons on the X4).
- **Apps on the X4 Pro work by touch.** App screens show a bar of four buttons at the bottom (Back / Select / < / >):
  tap = press, hold = hold (placing a flag in Minesweeper), and swipes left/right/up/down = the arrows (moving tiles in
  2048). Every app works, Pocket SDK apps included. Nothing changes on the X4.
- **An Xteink X4 Classic image**, `crosspoint-1.6.5-th.10-x4c.bin` (seven buttons like the X4, so every app works).
  Not yet tested on a device, and there is no emulator for it.

- **Fixed the home menu running off the screen with OPDS on** (Classic, Lyra 3 covers, RoundedRaff, on the X4 and
  X4 Pro): with the Apps tile it has six rows; rows now tighten when they would not fit, the last stays above the
  hint bar, and taps match what is drawn.
- **The web page on phones:** Optimize EPUB's Advanced Mode (JPEG quality, target device, rotation, overlap) no
  longer runs off the screen; its button groups wrap and take the sheet's width.

The X4 Pro files of th.7–th.9 were removed because of the tap bug; use this release.
