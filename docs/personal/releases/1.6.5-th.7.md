**รองรับ Xteink X4 Pro**

- **มีไฟล์สำหรับ X4 Pro แล้ว** ดาวน์โหลด `crosspoint-1.6.5-th.7-x4pro.bin` ฟีเจอร์ภาษาไทย หน้าหลัก แอป
  และนาฬิกาเหมือนรุ่น X4 ทุกอย่าง บน X4 Pro นาฬิกาใช้ชิป RTC ในเครื่อง ไม่ต้องรอซิงก์ Wi-Fi
- **X4 / X3 ใช้ไฟล์เดิม** `crosspoint-1.6.5-th.7-x3-x4.bin` อัปเดตผ่าน "Check for update" ได้ตามปกติ
  แต่ละรุ่นดาวน์โหลดเฉพาะไฟล์ของตัวเอง และเครื่องจะไม่ยอมติดตั้งไฟล์ของอีกรุ่น (ทั้ง OTA และอัปเดตจากการ์ด SD)
- **แก้:** ปุ่ม "แอป" บนหน้าหลักไม่มีไอคอนเมื่อใช้ธีม Lyra (ธีมเริ่มต้นของเครื่องใหม่)

X4 Pro เทสบน emulator เท่านั้น (eink-qemu 0.8.1: บูต การ์ด SD นาฬิกา จอสัมผัส ปุ่ม Home เปิดหนังสือไทย
พลิกหน้า หน้าแอป) ยังไม่ได้เทสบนเครื่องจริง ถ้าเจอปัญหาแจ้งใน Issues ได้

**Xteink X4 Pro support**

- **An X4 Pro image.** Download `crosspoint-1.6.5-th.7-x4pro.bin`. Thai reading, the home screens, the apps
  and the clock are the same as on the X4. On the X4 Pro the clock uses the built-in RTC chip, so it does
  not wait for a Wi-Fi sync.
- **X4 / X3 keep their file**, `crosspoint-1.6.5-th.7-x3-x4.bin`, and update through "Check for update" as
  before. Each model downloads only its own file, and a device refuses the other model's image (over OTA and from the SD card).
- **Fix:** the home "Apps" tile had no icon in the Lyra theme (the default on a new device).

The X4 Pro build is tested in the emulator only (eink-qemu 0.8.1: boot, SD card, clock, touch, the Home key,
opening a Thai book, turning pages, the Apps grid), not yet on a real device. Please report problems in Issues.
