**เฟส 4 และ 5: นาฬิกา แดชบอร์ด และสถิติการอ่าน**

- **นาฬิกาบนแถบสถานะ** X4 ไม่มีชิปนาฬิกา เวลาเลยตั้งจากอินเทอร์เน็ตทุกครั้งที่ต่อ Wi-Fi
  และเดินต่อระหว่างพักเครื่อง (ตั้งค่า → หน้าจอ → แถบสถานะ → นาฬิกา; เขตเวลา: ตั้งค่า → ระบบ → นาฬิกา)
- **หน้าจอพักแบบแดชบอร์ด** ตอนพักเครื่อง X4 ดึงภาพจากเซิร์ฟเวอร์แดชบอร์ด (เวลา อากาศ การอ่านวันนี้ ฯลฯ)
  เลือกได้ที่ ตั้งค่า → หน้าจอ → หน้าจอพักเครื่อง → แดชบอร์ด และตั้งที่อยู่ได้ที่ "ที่อยู่แดชบอร์ด"
  เลย์เอาต์เป็น HTML แก้และเพิ่มเองได้ในหน้า "แดชบอร์ด" ของเซิร์ฟเวอร์ (`server/` ใน repo นี้)
- **สถิติการอ่าน** ปุ่ม "สถิติ" บนหน้าหลัก: วันนี้กี่นาที กี่หน้า อ่านต่อเนื่องกี่วัน อ่านจบกี่เล่ม
  กราฟ 7 วัน และเล่มล่าสุด นับเฉพาะตอนที่พลิกหน้าอยู่จริง ซิงก์ขึ้นเซิร์ฟเวอร์พร้อมแดชบอร์ด
- **หน้าเว็บของเครื่องแบบใหม่** หน้าถ่ายโอนไฟล์ ตั้งค่า ฟอนต์ เข้าธีมเดียวกับเครื่อง ไอคอนทึบชุดเดียว
  มุมโค้งเป็นระบบเดียว ใช้บนมือถือสะดวก และมีโหมดมืด
- **อัปเดตจาก repo นี้ใช้ได้จริง** "ตรวจหาอัปเดต" เทียบเลข `-th.N` ได้แล้ว (เดิมไม่เคยเจอเวอร์ชันใหม่)

**Phases 4 and 5: clock, dashboard and reading stats**

- **Clock in the status bar.** The X4 has no clock chip, so the time is set from the internet whenever it joins Wi-Fi and keeps running through sleep (Settings → Display → Status bar → Clock; time zone under Settings → System → Clock).
- **Dashboard sleep screen.** When it sleeps, the X4 fetches an image from a dashboard server (time, weather, today's reading, ...). Pick Settings → Display → Sleep Screen → Dashboard and set "Dashboard URL". Layouts are HTML you can edit and add on the server's "Dashboard" page (`server/` in this repo).
- **Reading stats.** A "Stats" tile on the home screen: minutes and pages today, streak, books finished, a 7-day chart and the last book. Only time spent turning pages counts. Synced to the server with the dashboard.
- **Redesigned on-device web pages.** File transfer, settings and fonts in the device's look: one solid icon set, one corner system, phone-friendly, dark mode.
- **Updates from this repo work.** "Check for update" now compares the `-th.N` suffix (it never found a newer build before).
